# 블로그 초안 생성기 (BlogSeed)

씨앗 주제(seed)와 스토리보드를 넣으면 **소제목 5개 × 문단 3개** 구조의 블로그 초안을 만들고,
소제목마다 갤러리/카메라 이미지를 1장 이상 붙여 마크다운, HTML로 내보내는 안드로이드 앱.

## 산출물

- 디버그 APK: `app/build/outputs/apk/debug/app-debug.apk` (17 MB)
- 설치: 폰을 USB로 연결 후 `adb install -r app-debug.apk`, 또는 APK를 폰으로 옮겨 직접 설치(출처를 알 수 없는 앱 허용 필요)

## 화면

1. **홈** 씨앗 주제, 스토리보드(한 줄에 한 장면), 톤 4종 선택, 생성 버튼, 저장된 초안 목록
2. **편집** 제목/도입/소제목 5개(각 문단 3개)/마무리 인라인 편집, 소제목별 이미지 추가, 이미지 미비 경고 배너
3. **설정** 생성 엔진과 API 키, 모델명

## 생성 엔진

| 엔진 | 키 발급 | 비고 |
|---|---|---|
| Google Gemini (기본, `gemini-3.5-flash`) | aistudio.google.com/apikey | 무료 티어 분당 10회, 하루 1500회. 429가 뜨면 모델명을 `gemini-3.1-flash-lite`로 교체(분당 15회) |
| OpenAI | platform.openai.com/api-keys | **ChatGPT Plus 구독과 별개**, 크레딧 충전 필요 |
| Anthropic | console.anthropic.com | |
| 오프라인 템플릿 | 불필요 | 스토리보드를 5×3 골격으로 배분만 함 |

키는 앱 전용 SharedPreferences에만 저장되고 선택한 제공사 엔드포인트로만 전송된다.
모델명은 설정에서 직접 바꿀 수 있다(모델 이름이 바뀌어도 앱 수정 불필요).

## 형식 강제

- 모델 응답이 소제목 4개나 6개를 주면 5개로 잘라내거나 빈 소제목을 채운다.
- 문단이 5개면 뒤 3개를 합쳐 3문단으로, 1개면 빈 문단 2개를 붙여 사용자가 메꾸게 한다.
- 프롬프트에 em 대시 금지, 가운뎃점 금지, 상투적 도입 금지, 미확인 수치 금지를 넣었다.

## 내보내기

- **네이버용 텍스트 복사** (마크다운 기호 제거, 사진 자리에 `[사진 01]` 마커)
- **사진 갤러리에 저장** (`Pictures/BlogSeed/01_소제목.jpg`, 마커 번호와 파일명 번호 일치)
- 마크다운 클립보드 복사
- `.md` 파일 공유
- `.zip` (마크다운 + 이미지 폴더)
- `.html` 파일 공유 및 HTML 소스 복사 (이미지 base64 내장)

### 플랫폼별 경로

| 플랫폼 | 방법 |
|---|---|
| 네이버 블로그 | HTML 편집 모드 없음. `네이버용 텍스트 복사` + `사진 갤러리에 저장` 후, 붙여넣고 마커 자리에 사진 첨부 |
| 티스토리, 워드프레스 | `HTML 소스 복사` 또는 `.html` 파일. 이미지까지 한 번에 들어감 |
| 옵시디언, 깃허브 | `.md` 또는 `.zip` |

갤러리 저장은 안드로이드 10 이상에서 권한 없이 동작한다(MediaStore). 9 이하에서만 저장소 권한을 한 번 묻는다.

- JVM 단위테스트 4건 통과 (5×3 정규화, 오프라인 템플릿, 마크다운 출력, 이미지 미비 카운트)

  실제 API 호출은 폰에 설치해서 확인해야 한다.
