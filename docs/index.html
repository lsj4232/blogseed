블로그 초안 생성기

아이디어를 발행 가능한 초안으로. 씨앗 주제와 스토리보드를 넣으면 소제목 5개에 문단 3개씩 붙은 블로그 글을 만든다.

APK 내려받기 안드로이드 8.0 이상 · 버전 1.2

설치

  1. 위 버튼을 폰 브라우저에서 눌러 APK를 받는다.
  2. 다운로드 알림을 눌러 설치한다.
  3. "이 출처의 앱 설치 허용" 안내가 뜨면 허용한다. (구글 플레이를 거치지 않는 앱이라 한 번 묻는다.)

디버그 서명 APK다. 플레이스토어 배포본이 아니므로 설치 시 경고가 뜬다. 소스는 이 저장소에 전부 공개되어 있다.

글 생성 엔진 붙이기

앱은 키 없이도 오프라인 템플릿으로 5×3 골격을 만든다. 문장까지 써 주게 하려면 키를 넣는다.

  1. aistudio.google.com/apikey 접속, 구글 로그인
  2. Create API key 클릭, 새 프로젝트 선택 (결제 붙은 프로젝트를 고르면 과금된다)
  3. 발급된 키 복사. 카드 등록 화면 없음
  4. 앱 → 우상단 톱니바퀴 → Google Gemini 선택 → API 키 칸에 붙여넣기 (저장 버튼 없음)

무료 등급 기준 분당 10회, 하루 1500회. 무료 등급 입력은 구글 모델 학습에 쓰일 수 있으므로, 미공개 원고는 유료 등급을 쓰라. 키는 폰 앱 전용 저장소에만 남고 다른 서버로 보내지 않는다.

쓰는 순서

  1. 씨앗에 주제 한 줄. 예: 제주 3박4일 뚜벅이 여행
  2. 스토리보드에 한 줄에 한 장면씩. 줄 순서가 소제목 순서가 된다
  3. 톤 고르고 초안 생성
  4. 소제목 5개 각각 갤러리 또는 카메라로 사진 1장 이상 첨부
  5. 우상단 공유 아이콘에서 내보내기

플랫폼별 내보내기

플랫폼방법
네이버 블로그 HTML 편집 모드가 없다. 사진 갤러리에 저장 후 네이버용 텍스트 복사. 붙여넣고 [사진 01] 자리에 같은 번호 사진을 첨부
티스토리, 워드프레스HTML 소스 복사 또는 .html 파일. 이미지까지 한 번에 들어간다
옵시디언, 깃허브.md 파일 또는 .zip (마크다운 + 이미지)

만들어지는 형식

  • 소제목 정확히 5개, 소제목당 문단 정확히 3개 (모델이 어긋나게 답해도 앱이 맞춰 자르고 채운다)
  • 소제목마다 사진 1장 이상. 빠진 소제목은 빨간 경고로 표시
  • 소제목마다 어떤 사진을 넣으면 좋을지 제안과 캡션 초안
